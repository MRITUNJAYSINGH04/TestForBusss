## 🌍 What is God's Eye for Business?

**God's Eye for Business** transforms public geospatial data, surface web crawls, Google News feeds, and search indexes into an executive-level **B2B Prospecting & Corporate Intelligence Machine**.

Instead of browsing disjointed directories or paying for stale B2B lists filled with fake numbers:
1. You can enter **any company name, domain, or natural language search** (e.g. *"PLOT The Full Circle"*, *"find flexisales"*, or *"Find 10 AI startups in Pune with founder contact numbers"*).
2. The system executes autonomous deep surface/deep web reconnaissance, bypasses Cloudflare protections via multi-engine fallback (DuckDuckGo HTML + Google News RSS), extracts verified mobile numbers, direct corporate emails, and key decision-makers (Founders, CTOs, HR Heads).
3. Precision GPS coordinates are acquired and **the 3D Cesium globe camera automatically flies straight down to the exact building and floor level** (e.g. 15th Floor, Fountainhead, Phoenix Market City, Pune).
4. The system calculates high-impact operational bottlenecks ("Gaps") and outputs a hyper-personalized sales outreach pitch and cold email ready to close high-value B2B contracts.

### End-to-End Workflow:
1. **Target Acquisition**: User enters a company name, domain, or prospecting prompt in the Tactical Terminal (`plot Flexisales`), AI Chatbox, or Floating Search Bar.
2. **Surface & Deep Web Crawl**: The reconnaissance worker checks known landmarks, then launches parallel async HTTP requests against target domains (`/about-us`, `/contact-us`, `/team`, `/terms`).
3. **Resilient Multi-Engine Fallback**: If a target domain is down or protected by Cloudflare SSL errors (HTTP 526), the engine falls back to live DuckDuckGo HTML scraping and Google News RSS indexing to extract real corporate footprints.
4. **Zero-Mock Verification**: Strict regular expressions parse landlines (`020-XXXXXXX`), mobile numbers (`+91 XXXXX XXXXX`), verified emails (requiring valid alphabetical TLDs like `.in`, `.com`, `.co`), and executive LinkedIn profiles. Fake `555` numbers are strictly blocked.
5. **Geospatial Synchronization**: OpenStreetMap Nominatim resolves physical street and floor addresses to latitude/longitude coordinates.
6. **Sector-Tailored Gap Analysis**: The AI routing engine matches the target company against The Full Circle's 3DP capability matrix, producing an actionable cold outreach strategy.
7. **3D Camera Lock**: Cesium 3D camera smoothly flies across the globe to the physical facility, dropping a glowing beacon and rendering the complete dossier in the HUD.

### Detailed Breakdown of Key Modules

#### 1. Interactive Tactical Terminal CLI (`[>_ PLOT CLI]`)
- **Key Binding**: `Ctrl + ~` or `F2`, or click the green **`[>_ PLOT CLI]`** button in the tactical header.
- **Commands**:
  - `plot <company | url>`: Runs deep reconnaissance, extracts verified address, phone numbers, emails, and executives, plots node on the 3D Cesium globe, and automatically flies the camera to target coordinates.
  - `thefullcircle`: Instant shortcut: locks camera to 15th Floor, Fountainhead, Phoenix Market City, Pune and displays full facility dossier.
  - `flexisales`: Instant shortcut: locks camera to 18th Floor, AP81, Koregaon Park, Pune.
  - `scrape <target>`: Deep scrapes surface and open-source contact registries for real phone numbers, direct emails, and key decision-makers.
  - `prospect <query>`: Executes VIPER AI B2B prospector for 3DP / rapid prototyping client acquisition.
  - `contacts <target>`: Fast terminal printout of all verified direct phone lines, emails, founders, and LinkedIn profiles.
  - `gaps <target>`: Computes 3DP gap analysis matrix and tailored outreach pitch signed by The Full Circle.
  - `status`: Diagnostic telemetry of backend daemon, OpenRouter AI gateway, and 3D Cesium coordinates.
  - `clear`, `help`: Screen buffer clearing and help syntax guide.
- **Tech Stack**: Built with React 18, Tailwind CSS, Lucide icons, custom command execution engine with command history navigation (Up/Down arrow keys) and Tab autocomplete.

#### 2. Photorealistic 3D Geospatial Viewport & Pins
- **3D Globe Engine**: Built on CesiumJS v1.120 and Resium. Renders digital terrain, glowing beacon pins, and flight camera arcs.
- **Visual Filters**: Includes GLSL sensor simulation filters: CRT Scanlines, Surveillance Mode, Night Vision, and Retro Wireframe.
- **Dynamic Pin Generation**: `renderCompanyPins()` in `frontend/src/lib/nodes.ts` creates glowing point beacons with altitude offsets, color-coded by industry and outreach status.

#### 3. Claude-Style AI Prospector Console
- **AI Gateway**: Routes requests through `backend/app/core/ai_router.py`. Supports OpenRouter free tier (`openrouter/free`) with automatic failover to Google Gemini Flash.
- **Intent Parsing**: Detects target roles (Founders, CTOs, HR heads), city hub (Pune, Mumbai, Bangalore), and industry.
- **Zero Mock Provenance**: Extracted leads are validated against authentic web crawls before being presented.

#### 4. Sector-Specific 3DP Gap Analysis Engine
- **Taxonomy Matrix**: Pre-configured with intelligence for 12+ real-world sectors:
  1. **Industrial Hardware & CNC**: Replaces 3-week subtractive machining lead times with 48h functional 3D prototype turnarounds.
  2. **Healthcare & Medical Devices**: Sub-50-micron biocompatible patient-specific surgical guides and anatomical replicas.
  3. **Robotics & Drones**: Lightweight, continuous-fiber SLS carbon-nylon end-effectors and drone motor mounts.
  4. **Architecture & Real Estate**: Monolithic 72-hour BIM scale architectural display models.
  5. **Consumer Electronics**: Snap-fit functional enclosures and silicone mold masters with smooth matte finishes.
  6. **B2B Demand Generation**: Decision-maker connect rate optimization for sales intelligence firms like Flexisales.
- **Outreach Signature**: Every generated cold email is signed by *"Founder & Operations Lead, The Full Circle (3D Prototyping & Additive Manufacturing)"*.

## 🔒 Zero-Tolerance Fake Data Policy

Unlike traditional mock prospecting tools, **God's Eye for Business enforces a strict zero-fake-data policy**:

1. **No Synthetic Numbers**: Dummy numbers (e.g. `+1 800 555-0199` or `+91 20 6703 0000` on random companies) are completely stripped.
2. **Explicit Null Representation**: If a phone or email cannot be verified via public websites, DNS records, or open registries, it explicitly outputs `Not Publicly Listed` with a confidence score.
3. **Alphabetical TLD Validation**: Email regex checks require valid alphabetical Top-Level Domains (`.in`, `.com`, `.co`, `.org`, `.io`, etc.) and reject invalid strings like npm version tags (`component@1.0.6`).
4. **Direct Executive Provenance**: Leadership names are extracted directly from official `/team`, `/about-us` pages, or verified LinkedIn public listings.

## ⚡ Quick Start & Installation

### Prerequisites
- **Node.js**: v18.0 or later (v20+ recommended)
- **Python**: v3.11 or later
- **Git**

### 1. Clone Repository & Set Up Virtual Environment

```bash
# Clone the repository
git clone https://github.com/bilawalsidhu/gods-eye-view.git
cd gods-eye-view

# Set up Python virtual environment
cd backend
python -m venv .venv

# Activate virtual environment (Windows PowerShell)
.venv\Scripts\Activate.ps1
# Or on macOS/Linux:
# source .venv/bin/activate

# Install backend dependencies
pip install -r requirements.txt
cd ..
```

### 2. Configure Environment Variables

Create `backend/.env` (or configure via app):
```env
# OpenRouter Free LLM Gateway (Pre-configured)
OPENROUTER_API_KEY=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
OPENROUTER_BASE_URL=https://openrouter.ai/api/v1
OPENROUTER_DEFAULT_MODEL=openrouter/free

# Database (SQLite default; PostgreSQL optional)
DATABASE_URL=sqlite:///./gods_eye_production.db

# Optional Services
GEMINI_API_KEY=your_gemini_api_key_here
SERPAPI_API_KEY=your_serpapi_key_here
```

### 3. Install Frontend Dependencies

```bash
cd frontend
npm install
cd ..
```

### 4. Run Both Servers

**Terminal 1 — Backend FastAPI Server**:
```powershell
backend\.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000 --reload
```
*Backend runs on: `http://127.0.0.1:8000` (Docs: `http://127.0.0.1:8000/docs`)*

**Terminal 2 — Frontend Next.js Dev Server**:
```powershell
npm --prefix frontend run dev
```
*Frontend runs on: `http://localhost:3000`*
